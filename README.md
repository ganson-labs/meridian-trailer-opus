# MERIDIAN

Трейлер несуществующей игры, который Claude Opus 5.5 написал целиком кодом для ролика «Opus 5.5 против GPT-6 Astra» на канале «гансон:»: https://youtu.be/wguBNzeBfTA

Картинка и музыка создаются прямо в браузере при показе: шейдеры WebGL и синтез звука в Web Audio. Готовых видео, картинок, моделей и аудиофайлов в проекте нет, внешних зависимостей тоже.

## Запуск

- **Windows:** `play.cmd`. Откроет трейлер во весь экран в Chrome или Edge с отдельным профилем, чтобы звук включился сам.
- **Любая система:** открой `index.html` в Chrome или Edge и нажми на экран или любую клавишу, чтобы пошёл звук.

Клавиши: пробел — пауза, `R` — сначала, `F` — полный экран, `D` — отладочная панель.

Этот README добавлен после теста, чтобы трейлер было проще запустить. Код в `src/` и `index.html` оставлен таким, каким его сделала модель.
